# RSI Discovery Month 4.10.2 · sPg Compact Guide

[Magyar](#magyar) · [English](#english)

## Magyar

**1.0.6 – egyfájlos, offline is működő, kétnyelvű event-kalauz.**

Nyisd meg az `index.html` fájlt. Felül azonnal látszik a négy jutalomsáv (Transport, Collection, Defense, Overall),
a 16 jutalom és az állítható pontszámláló. Lent a leghasznosabb gyors útvonalak.
A **31 küldetés** és a **22 külön megszerezhető, SCMDB-ből származó BP-recept**
lenyitható, kereshető részben szerepel.

- Beépített HU/EN váltó; a választott nyelv és a megadott pontok helyi böngészőtárolóban maradnak.
- A felhasználó által feltöltött négy komponenskép be van ágyazva a HTML-be.
- A VerseHub jutalomképeit nem másoltuk: a fájlokat nem tudtuk hitelesen beszerezni. Eredeti képek az oldalán megtekinthetők.
- A küldetésjutalom-komponensek és a külön megszerezhető BP-k nincsenek összekeverve.
- Ez nem hivatalos RSI/CIG alkalmazás.

**GitHub Pages:** Settings → Pages → Source: GitHub Actions. A mellékelt workflow a gyökérbeli `index.html` fájlt szolgálja ki.

## English

**1.0.6 – bilingual, offline-capable, single-file event guide.**

Open `index.html`. The four reward tracks (Transport, Collection, Defense, Overall),
16 rewards and editable point counters are immediately visible, followed by fast-track recommendations.
The **31 missions** and **22 independently obtainable SCMDB blueprint recipes**
are available in compact, searchable collapsible sections.

- Built-in HU/EN switch; language and entered progress are saved in local browser storage.
- Four user-supplied component reference screenshots are embedded into the HTML.
- Original VerseHub reward images were not copied because their files could not be reliably obtained. View them on VerseHub.
- Event components are separate from independently obtainable blueprints.
- This is an unofficial RSI/CIG community tool.

**GitHub Pages:** Settings → Pages → Source: GitHub Actions. The included workflow serves the root `index.html`.
