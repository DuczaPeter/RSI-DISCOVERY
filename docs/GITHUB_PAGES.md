# GitHub Pages / GitHub Pages beállítás

## Magyar
1. Töltsd fel a teljes repositoryt.
2. Settings → Pages.
3. Source: **GitHub Actions**.
4. Push a `main` branchre.
5. A mellékelt workflow publikálja az `index.html` oldalt.

## English
1. Upload the full repository.
2. Settings → Pages.
3. Source: **GitHub Actions**.
4. Push to `main`.
5. The included workflow publishes `index.html`.
